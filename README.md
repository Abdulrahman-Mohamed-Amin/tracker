# مسار — متتبّع العادات

تطبيق ويب بسيط (HTML/CSS/JS بدون أي مكتبات) لتتبع عادتين يوميتين:

- **الجيم**: نمط متكرر يومين حضور ويوم راحة (٤-٥ أيام/أسبوع تقريبًا).
- **القراءة**: هدف يومي بعدد صفحات محدد.

قابل للتوسّع لإضافة أي عادة جديدة من داخل التطبيق نفسه، مع رسوم بيانية أسبوعية/شهرية.
كل البيانات تُحفظ محليًا على جهازك عبر `localStorage` ولا تُرسل لأي خادم.

## الملفات

- `index.html` / `style.css` / `script.js` — الصفحة الرئيسية (تسجيل يومي، أسبوعي، شهري).
- `charts.html` / `charts.css` / `charts.js` — صفحة الرسوم البيانية.

## التشغيل

افتح `index.html` مباشرة في أي متصفح، أو استضفه على GitHub Pages.
